SLIDE 2: THE PROBLEM
================================================================================
Current Surveillance Systems Have Critical Limitations:

1. PRIVACY VIOLATIONS
   • Continuous recording of identifiable faces
   • No anonymization or privacy protection
   • Potential for misuse and unauthorized tracking
   • Legal and ethical concerns

2. REACTIVE APPROACH
   • Incidents discovered AFTER they occur
   • Delayed response times
   • Relies entirely on human monitoring

3. OPERATOR FATIGUE
   • Impossible to monitor multiple feeds 24/7
   • Human error and attention lapses
   • Expensive manpower requirements

4. UNDERUTILIZED INFRASTRUCTURE
   • Cameras used only for passive recording
   • No intelligent analysis or alerts
   • Expensive equipment not reaching potential

REAL-WORLD IMPACT: Delayed responses, privacy violations, inefficiency


SLIDE 3: OUR SOLUTION - VIGIL
================================================================================
A Privacy-First Intelligent Surveillance Decision-Support System

KEY PRINCIPLE: "Detect Events, NOT Identities"

VIGIL FOCUSES ON:
✓ What is happening (events, behaviors, patterns)
✓ NOT Who is present (no facial recognition)

CORE CAPABILITIES:
• Real-time person counting
• Bag/object detection (unattended items)
• Crowd density monitoring
• Risk level assessment
• Automatic face anonymization
• Live alerts and statistics

RESULT: Proactive safety monitoring with complete privacy protection


SLIDE 4: WHY PRIVACY MATTERS
================================================================================
VIGIL's Privacy-By-Design Approach:

1. NO FACIAL RECOGNITION
   • No identity matching or tracking
   • No database of faces
   • Focus on behaviors, not identities

2. REAL-TIME ANONYMIZATION
   • All faces automatically blurred using MediaPipe
   • Anonymization happens BEFORE display or storage
   • "ANONYMIZED" badges on all video streams

3. NO RAW VIDEO STORAGE
   • Only metadata stored (counts, timestamps, risk scores)
   • No identifiable video data persisted
   • Cannot be misused for unauthorized tracking

4. TRANSPARENT & AUDITABLE
   • All actions logged
   • De-anonymization requires supervisor approval
   • Full audit trail for accountability

COMPLIANCE: Privacy-by-design, GDPR-aligned, ethically responsible

SLIDE 6: ML/AI PIPELINE
================================================================================
Real-Time Intelligence Pipeline:

INPUT: Video Stream
   ↓
STEP 1: OBJECT DETECTION (YOLOv8)
   • Detects: People, Backpacks, Handbags, Suitcases
   • Confidence threshold: 50%
   • Real-time inference
   ↓
STEP 2: FACE DETECTION & ANONYMIZATION (MediaPipe)
   • Detects all faces in frame
   • Applies Gaussian blur to face regions
   • Irreversible anonymization
   ↓
STEP 3: RISK ASSESSMENT
   • Calculates crowd density
   • Counts persons and bags
   • Evaluates risk level: LOW/MEDIUM/HIGH
   ↓
STEP 4: STATISTICS & ALERTS
   • Real-time counts via WebSocket
   • Alert generation for high-risk scenarios
   • Dashboard updates
   ↓
OUTPUT: Anonymized video + Live statistics + Alerts

SLIDE 14: CHALLENGES & SOLUTIONS
================================================================================

CHALLENGE 1: Real-time Video Processing
• Problem: Processing HD video in real-time is computationally intensive
• Solution: Optimized YOLOv8n (nano) model, frame rate throttling, lazy pipeline loading

CHALLENGE 2: Privacy Guarantees
• Problem: Ensuring no identifiable data ever leaves the system
• Solution: In-memory anonymization BEFORE any display/storage, no raw video persistence

CHALLENGE 3: Accurate Detection
• Problem: YOLOv8 can miss objects in poor lighting
• Solution: Confidence thresholds, multiple object classes, bounding box visualization

CHALLENGE 4: WebSocket Scalability
• Problem: Multiple clients streaming live data
• Solution: Efficient connection management, separate WebSocket per camera, rate limiting

CHALLENGE 5: User Experience
• Problem: Complex system needs simple interface
• Solution: Professional corporate UI, clear visual indicators, real-time feedback

SLIDE 17: DEPLOYMENT & USAGE
================================================================================

SYSTEM REQUIREMENTS:
• Python 3.10+
• Node.js 16+
• 8GB RAM minimum
• Modern web browser (Chrome/Firefox)
• Windows/Linux/macOS

INSTALLATION:
1. Clone repository
2. Setup Python virtual environment
3. Install backend dependencies (pip install -r requirements.txt)
4. Install frontend dependencies (npm install)

RUNNING THE SYSTEM:
Backend:

  uvicorn app.main:app --host 127.0.0.1 --port 8000

SLIDE 21: Q&A PREPARATION
================================================================================

ANTICIPATED QUESTIONS & ANSWERS:

Q: How accurate is the person counting?
A: YOLOv8 achieves 85-95% accuracy in good lighting. We use confidence thresholds to minimize false positives.

Q: Can the anonymization be reversed?
A: No. Face blurring uses Gaussian blur which is irreversible. Original faces cannot be recovered.

Q: What if someone wears a mask?
A: The system detects persons via full-body detection, not just faces. Masks don't affect person counting.

Q: How does it handle privacy regulations?
A: VIGIL is privacy-by-design compliant. No identifiable data stored = no GDPR/privacy law violations.

Q: Can it detect weapons?
A: Current version focuses on persons/bags. Weapon detection can be added with additional YOLO training.

Q: What's the cost compared to traditional systems?
A: Uses standard hardware, open-source ML models. Lower cost than proprietary solutions.

Q: How many cameras can it handle?
A: Current demo: 3 cameras. Architecture scales to 50+ cameras with proper hardware.

Q: Is it real-time?
A: Yes. 10-15 FPS processing with <100ms WebSocket latency for statistics.
